# TDK Game Development

Game development workspace for Godot mobile projects.

## Planned projects

- `game-dev/anime-soccer/` — 2D anime soccer prototype.
- `game-dev/horror-puzzle/` — 3D first-person horror puzzle prototype.
- `game-dev/tools/` — Godot editor addon management.

All game code and imported third-party assets should be reviewed for compatibility and licensing before integration. Never commit secrets or Android signing keys.
